# 城池战争 (CityWar)

本地多人策略游戏，支持桌面客户端和浏览器运行。后端使用 Python Flask + Socket.IO，前端使用 HTML/CSS/JavaScript，桌面端通过 pywebview 嵌入原生窗口。

## 游戏简介

- **类型**：本地多人策略游戏
- **人数**：2-8 人
- **时长**：约 15-30 分钟
- **胜利条件**：成为最后存活的玩家

每位玩家初始拥有 **100 个城池**，每轮选择一种行动。当城池数降至 0 以下时玩家死亡，最后存活者获胜。

## 回合操作

每轮玩家从以下四种基础操作中选择一种：

| 操作 | 说明 |
|------|------|
| **攻城** | 选择一名玩家，使其城池减少 20（第 6 轮后为 40）。若双方互攻，各自伤害减少 100（最低为 0） |
| **守城** | 本回合被攻城时生效：攻击方城池减少 10（第 6 轮后为 20），转移给防御方 |
| **打野** | 与系统猜拳。**胜**：随机获得一张技能卡；**负**：城池增加 10（第 6 轮后为 20）；平局算胜 |
| **约战** | 选择玩家并设赌注（上限为双方较低城池数的 60%），进行俄罗斯轮盘赌。6 发转轮（第 6 轮后为 10 发），1 发子弹，发起者先手，轮流选择开 1-3 枪，中弹者输掉赌注 |

## 后期阶段（第 6 轮起）

新增两种操作：

| 操作 | 说明 |
|------|------|
| **修城** | 立即获得 40 城池，但本轮受到伤害时伤害翻倍且修城失效 |
| **结盟** | 邀请一名玩家结盟（需对方同意）。盟期内双方伤害与奖励平分；解盟时双方猜拳，赢家获全部奖励，输家承担全部伤害 |

### 拍卖会

第 6 轮起每两轮举行一次技能卡拍卖：
- 起拍价 = 当前存活玩家最低城池数
- 最小加价 10 城池
- 30 秒时限，无人竞拍则流拍

## 技能卡（20 张）

### 攻击类
| 卡牌 | 效果 |
|------|------|
| 火攻卡 | 对目标造成 30 伤害 |
| 奇袭卡 | 对目标造成 20 伤害，无视守城 |
| 连弩卡 | 攻击两名不同玩家，各造成 15 伤害 |
| 破城卡 | 对目标造成 50 伤害，自己损失 10 |
| 毒计卡 | 使目标下回合无法行动 |

### 防御类
| 卡牌 | 效果 |
|------|------|
| 铁壁卡 | 下回合受到伤害减半 |
| 空城卡 | 下回合若被攻击，攻击方损失 20 |
| 援军卡 | 立即获得 25 城池 |
| 诈降卡 | 下回合若被攻击，免疫并反弹 15 |
| 迁都卡 | 获得 15 城池，下回合无法被选中 |

### 资源类
| 卡牌 | 效果 |
|------|------|
| 屯田卡 | 接下来 3 回合每回合获得 10 城池 |
| 商路卡 | 从所有其他玩家处各获得 5 城池 |
| 征税卡 | 获得当前城池数 20% 的额外城池 |
| 募兵卡 | 立即获得 20 城池，但下回合必须攻城 |
| 丰收卡 | 获得 30 城池，但跳过下回合 |

### 特殊类
| 卡牌 | 效果 |
|------|------|
| 离间卡 | 指定两名玩家，他们下回合无法互相攻击 |
| 侦查卡 | 查看一名玩家的手牌和下回合意图 |
| 伪装卡 | 下回合你的行动显示为随机行动 |
| 急救卡 | 城池 < 0 时使用，获得 20 城池（救命一次） |
| 逆转卡 | 与一名玩家交换城池数（双方需 > 50） |

## 通信与信息

- **公共聊天**：所有存活玩家可见，死亡玩家消息对存活玩家不可见
- **公共会议**：每轮结束公布每位玩家城池数、本轮增减、已流出技能卡总数
- **日志隐私**：详细游戏日志仅上帝视角可见

## 死亡与观战

- 城池数 < 0 时死亡，进入**观战模式**（上帝视角）
- 上帝视角可查看所有玩家的操作、技能卡、结盟详情、完整游戏日志

## 安装与运行

### 方式一：下载可执行文件（推荐，无需安装 Python）

前往 [Releases](https://github.com/zz632/city-war/releases) 页面下载对应平台的压缩包：

| 平台 | 服务器 | 客户端 |
|------|--------|--------|
| macOS | `city-war-server-macos.zip` | `city-war-client-macos.zip` |
| Windows | `city-war-server-windows.zip` | `city-war-client-windows.zip` |

解压后先启动 `citywar-server`（服务器），再启动 `citywar-client`（客户端）即可游戏。局域网内设备也可直接用浏览器访问服务器地址。

### 方式二：从源码运行

**环境要求：** Python 3.9+

**安装依赖：**

```bash
pip install -r requirements.txt
```

**启动游戏服务器：**

```bash
python3 server.py
```

服务器默认在 `http://localhost:5000` 启动（如端口被占用会自动切换），同时显示局域网访问地址。

**启动游戏客户端：**

```bash
python3 run.py
```

客户端会打开桌面窗口，选择"本地游戏"后输入服务器地址和端口即可连接。同一台电脑不可多开客户端。

**直接用浏览器访问：**

局域网内的设备（包括手机）可直接在浏览器中输入服务器地址访问游戏，同一设备不可重复加入同一房间。

## 项目结构

```
city-war/
├── server.py               # 服务器启动器（独立运行）
├── run.py                  # 游戏客户端启动器（pywebview 桌面窗口）
├── app.py                  # Flask 主应用（不可独立运行）
├── requirements.txt        # Python 依赖
├── build_macos.sh          # macOS 打包脚本
├── citywar.spec            # PyInstaller 打包配置
├── game/
│   ├── models.py           # 数据模型、技能卡定义
│   ├── manager.py          # 房间管理器（核心游戏引擎、IP 防多开）
│   └── skills.py           # 技能卡效果实现
├── websocket/
│   └── events.py           # Socket.IO 事件处理与游戏流程
├── static/
│   ├── css/
│   │   ├── reset.css       # CSS 重置
│   │   └── main.css        # 主样式
│   └── js/
│       └── main.js         # 前端主逻辑
└── templates/
    ├── index.html          # 首页（创建/加入房间）
    ├── lobby.html          # 游戏大厅
    └── game.html           # 游戏主页面
```

## 技术栈

- **后端**：Python 3 + Flask + Flask-SocketIO（threading 模式）
- **前端**：HTML5 + CSS3 + Vanilla JavaScript + Socket.IO Client
- **桌面端**：pywebview（原生窗口嵌入）
- **防多开**：TCP 端口锁（客户端）+ IP 房间限制（服务端）
